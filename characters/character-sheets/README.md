# Character Sheets

One file per character. Use template:

```md
# [Character Name]

- Role:
- Species:
- Age:
- Appearance:
- Personality (3 traits):
- Backstory:
- Motivation:
- Relationship to Flower/Petals:
- Arc:
- Fate in each ending:
- Voice sample:
```

Create e.g.:
- `quote.md`
- `curly.md`
- `new-protagonist.md`
- `flower-girl.md`

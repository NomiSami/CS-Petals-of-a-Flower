# Island Map — Petals of a Flower

## Overview
Dozens miles across, held aloft by Core in Labyrinth. Upper surface meadows/cliffs, below honeycomb. Cradle lit by Crack (seam overhead). Morning = light hits Reservoir.

- **Reservoir:** Bottom dark crack in/out, light hits last, fish shy sign "K.", Kanpachi dock, Mahin path
- **Farm:** Every road up from Reservoir passes through, meal flowers never red
- **Hall:** Chimney, larger than rest
- **Shack:** Old sagging, later Toroko hiding
- **House:** Round, earth walls cream flower border, round window rock, loft ladder, humming machine corner
- **Cage:** Village cage where Sue locked

## Old Village / Big Village
Miles overgrown lanes, intact empty homes, still hub traders gatherers, few holdouts.
- **Terraces:** Flower Terraces sacred origin soul flowers, one keeper Ume
- **Lantern Row:** Hozuki lights
- **Old Square:** Market Day traders, Cthulhu, beetle-back merchant, Yomogi
- **Burrows:** Lower
- **Bell Hall:** Bell, murals war + Red Demon
- **Edge-houses:** Went dark first, Mugen
